
# Mi portafolio personal - Natalia Suarez

## Descripción

Este proyecto es mi primer portafolio personal,
hecho durante el primer trimestre del curso
de Lenguaje de Marcas.

El objetivo es mostrar información sobre mí,
mis conocimientos y los proyectos que he realizado
durante el curso.

## Páginas del portafolio

- index.html: presentación personal y proyectos destacados.
- sobre-mi.html: trayectoria, aficiones y objetivos.
- proyectos.html: seis proyectos realizados durante el trimestre.
- cv.html: formación académica, competencias e idiomas.
- contacto.html: formulario y enlaces de contacto.

## Tecnologías utilizadas

- HTML5
- Visual Studio Code
- Git
- GitHub

## Características

- Estructura HTML semántica.
- Navegación entre cinco páginas.
- Imágenes con texto alternativo.
- Tablas de formación y competencias.
- Formulario con validación HTML.
- Código validado con W3C sin errores.
